# radiosol.world

An unofficial, fan-made site. **RADIOSOL** belongs to TripletConcept, Yodez,
Hius and WhereaboutsUnknown — [the game on Steam](https://store.steampowered.com/app/2934330/).

Right now this is a holding page. Nothing is published here, and nothing will
be without the RADIOSOL team's say-so. If you are from the team and would
rather it did not exist, say so and it comes down: **stef@picxi.uk**

## What is here

| file | what |
|---|---|
| `index.html` | the holding notice |
| `404.html` | the not-found notice |
| `favicon.svg` | our own mark |
| `CNAME` | the custom domain for GitHub Pages |

Self-contained: fonts are inlined as data-URI woff2 (IBM Plex Mono and
Silkscreen, both SIL Open Font License), and the pages make **zero outbound
requests**. The only external URLs are links a reader has to click.

## No analytics

There is no tracking script on any page here, and there never will be. The
page records nothing about you — no script, no cookie, no beacon. Visit
counts, if any, come from the network edge, the way any server sees requests.
